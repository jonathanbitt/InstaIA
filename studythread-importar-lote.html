Importar Posts em Lote — Firebase Firestore
📋 Formato do JSON de entrada
Cole um array de posts. Cada post pode ter os campos abaixo.
Apenas conteudo é obrigatório — os demais têm valores padrão. 
{
  "posts": [
    {
      "conteudo": "Por que Kant distingue fenômeno de nômeno?",
      "tipo": "filosofia",       // padrão: "outro"
      "status": "ativo",         // padrão: "ativo"
      "inedito": true,           // padrão: true
      "comentarios": [           // opcional — comentários iniciais
        {
          "autor": "Kant_IA",
          "tipo": "explicacao",  // resposta|aula|explicacao|exercicio|correcao|sintese
          "origem": "ia",        // "ia" ou "manual"  (padrão: "ia")
          "conteudo": "A distinção entre fenômeno (o que aparece) e nômeno (a coisa-em-si)…"
        }
      ]
    },
    {
      "conteudo": "Prove que √2 é irracional.",
      "tipo": "matematica"
    }
  ]
}
Tipos válidos: filosofia · matemática · idioma · lógica · ciência · história · literatura · outro
IDs são gerados automaticamente. Timestamps também são gerados automaticamente.
